# Jardín Amazónico

Web mobile-first de Jardín Amazónico — plantas vivas de colección y artesanías amazónicas, conectando cada compra con comunidades artesanas indígenas del Perú.

## Stack previsto (ver PRD para detalle)

- Next.js 15 (App Router) + React 19 + TypeScript
- Tailwind CSS v4
- Lucide Icons
- Framer Motion
- Vercel (hosting)
- Google Sheets API (captura de leads de membresía)
- MercadoPago (links estáticos de pago)
